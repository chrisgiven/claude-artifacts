⚠ BCP/DR Client Alert — 2 Active Items

Browser-based AI agents can be hijacked: BragJack hits Perplexity Comet, and the ChatGPT Lockdown Mode bypass is now public The Hacker News reported BragJack, which hijacks AI agents that run inside a browser; Perplexity Comet is named. Check Point also published a zero-click way around ChatGPT Lockdown Mode in the desktop app: HTML previews in code blocks escaped their sandbox and could pull chat data out. OpenAI fixed it on Sept 18, and no in-the-wild use is reported. Action: tell clients that agentic browsers do not belong on endpoints that handle recovery runbooks or customer data. Confirm ChatGPT desktop clients are current, and do not treat Lockdown Mode alone as a data-loss control.

GitHub Copilot CLI and Grok exposed to local file reads through hidden web-page instructions Researchers described 'Cryptographic Context Injection', where hidden instructions on a web page get a CLI agent to read local files. Patch status is not yet confirmed. Action: clients running Copilot CLI on build or DR-automation hosts should limit which directories it can read and keep it off machines that hold credentials until a fix is confirmed.
