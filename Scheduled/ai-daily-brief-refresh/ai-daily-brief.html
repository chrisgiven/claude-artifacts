⚠ BCP/DR Client Alert — 2 Active Items

Claude Code "Don't ask again" approvals are leaking credentials into public repos Apiiro research (published Nov 5–6) found that approving a command with "Yes, and don't ask again" writes it, credentials included, into .claude/settings.local.json. Thousands of secrets reportedly reached public GitHub (reports range from 1,122 files to 2,539 secrets). Any client using Claude Code should check whether that file is tracked (`git ls-files`, `git log`), add it to .gitignore, and rotate any exposed keys. Deleting the file does not revoke anything.

Microsoft 365 Copilot connector write actions are now GA Copilot Chat and Cowork can now create, update or delete records in connected apps, depending on the connector. Clients should review connector permissions and Entra ID policies before users start pointing agents at systems of record, and log these actions as changes in their change-management records.
