GitHub Copilot can now drive desktop applications — a new path to client data on developer machines GitHub put computer use into public preview on Oct 1 for the Copilot CLI and the Copilot app on macOS and Windows. For clients with Copilot Business or Enterprise, ask whether preview features are enabled by policy, which machines hold production consoles or regulated data, and whether screen content handled by the agent is covered by existing DLP and logging.

Clients who have not reviewed agent settings will see these appear without an admin decision. Have tenant admins confirm the intended state and the cost-management limits (Copilot Studio agents are added to cost management in October) before users find them.
