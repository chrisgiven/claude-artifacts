LAB / TRIPLive

Tripwire

Network intrusion detection and deception for a UniFi network. Reads the gateway's firewall log and the controller API, then runs SSH, telnet and HTTP decoys that nothing legitimate should ever touch — so every hit is signal. Captures each credential and keystroke, maps them to MITRE ATT&CK, and clusters sessions by SSH client fingerprint to recognise one operator across rotating addresses. LAB / BSTNLive

Bastion

A vulnerability scanner for the home network, built on Nessus principles. Every device gets a port and service scan with safe checks only, CVE matching, and direct version checks against the device itself where it allows one. Each finding carries a plugin ID, a CVSS score and a fix. Scans run twice a day and are compared with the last one, so a device that shows up at night or a port someone opened and forgot is flagged as new. Pick devices and push updates where there's a local path to do it; everything else gets exact manual steps.

LAB / COINLive

Coin Scout

Photograph a handful of coins and get Keep, Check or Spend for each one. Claude only reads the coin: date, mint mark, series, visible errors.
